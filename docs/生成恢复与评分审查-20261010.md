# 生成恢复、评分与手机 PDF 验收

## 本次修改

- 批改默认等待完整结果；编辑页可勾选「边生成边显示（可选）」。浏览器记住开关，新设置默认关闭，普通输出和流式输出遵守同一评分规则。
- 收到任务号就保存历史，标注生成中。关闭页面后，再打开原链接或当前浏览器的首页，会继续读取同一个任务，不再重复提交模型或消耗一次新额度。
- 完成、失败和生成中在历史中分别显示；账号同步合并时，已完成记录不会被其他设备的旧生成中记录覆盖。只自动恢复最近一个未完成任务，其他任务可以在历史中打开。
- 网站已经打开时跳转到分享链接，也会加载对应作业；迟到的首屏自动选课请求不能覆盖恢复中的任务。
- 取消等待后仍保留后台任务。旧任务稍后完成不会抢走新任务的页面或解锁新任务按钮。任务真正失败、服务重启中断或永久丢失时不能凭空恢复结果，会显示原因。
- 学生结果和自测卷直接生成可搜索的 PDF，提供生成进度、再次下载链接，以及浏览器支持时的文件分享按钮。结果未完成时禁止导出。
- PDF 字体覆盖中文、英文和常用 IPA 音标，避免音标显示为字符编码。仍使用分页文本排版，长文不靠一张超长截图保存。

## 用户提供的 58 分作业：判断

不能根据一次作业证明所有用户评分普遍偏低，也不能直接把这份作业提到高分。它有多处会改变信息的实质误译：

| 原文信息 | 译稿问题 | 判断 |
| --- | --- | --- |
| seventy-two | 译成 22 岁 | 人物年龄错误，应修正 |
| forty-odd households | 误解成人家房屋的面积 | 数量和对象错误，应修正 |
| municipal official | 译成「众多官方」 | 身份和单复数错误，应修正 |
| ground will not outlive us | 理解成土地容不下人 | 改变原意，应修正 |
| power poles | 译成「承重的地洞」 | 实物词义错误，应修正 |
| offers little comfort | 译成带来些许安慰 | 否定倾向变为肯定，应修正 |

但旧批改存在问题：

1. 英译汉结果出现了汉译英评分维度，例如「语法与时态」。
2. 部分可接受意译、措辞差异被当成必须改的错误；专名建议和词源解释也有未经核实的断言。
3. 参考译文包含原文未直接写明的信息，不能要求学生为此补译。
4. 旧备用评分会按分析条数扣分，包括可选润色；建议多不等于错误多。本例的 58 是模型给出的分数，不能把它归因于这个备用公式。

因此，较低分数有真实误译依据，但旧版具体扣分依据不够严谨，不能把 58 当成人工阅卷的精确定分。

## 评分校准与复测

- 两种方向明确使用各自五项维度，每项 20 分；要求总分与分项一致。
- 原文为信息判断依据；参考译文和 AI 对照译文都不保证唯一正确，不能按字面相似度评分。
- 真正错漏、可选润色、对照学习分开标注；可选润色和学习点不扣分；要求同一处事实错误不重复扣分，核对学生全文是否已表达相关信息。
- 学生译法已成立时予以认可，AI 版本不再强行要求更高级；评价优先给具体优点及 2–3 个重要改进方向。
- 模型无法补出整体评分时保留逐句批改并显示「评分暂不可用」，停止伪造数字评分。
- 通过正式服务器所用模型作有限复测：原稿为 **62 分**，对照稿为 **94 分**；对照稿未判必须改的错误。历史作业仍保留原有 58 分，本次没有修改既有结果或成绩。

**边界：**这些是有限样本，不能证明全站评分已稳定校准。复测仍有少量分项评价边界不清晰的情况，模型可能误判或重复评价同一事实。分数只能作为学习参考；重要作业建议教师复核。后续应选取不同水平、不同译法的匿名样本，进行教师盲评及模型对照，重点检查重复扣分和意译容忍度，而不是统一加分。

## 测试记录

| 场景 | 结果与范围 |
| --- | --- |
| 默认等待 → 关闭页面 → 打开裸首页 | 同一个任务恢复完成；模拟模型只收到一次提交 |
| 未完成分享链接 / 历史打开 | 自动继续读取；无新提交 |
| 取消旧任务等待后启动新任务 | 旧任务完成不会清掉新任务的忙碌状态 |
| 已完成与生成中账号历史合并 | 保留已完成状态及必要元数据 |
| 安卓 Chrome 手机视口 | 真实 PDF 下载及再次下载链接通过，无横向溢出或页面异常 |
| iPhone Safari WebKit 引擎 | 同上；使用 WebKit 引擎与 iPhone 设备参数，不冒充实体 iPhone 测试 |
| 微信 UA 仿真 | 下载及提示路径通过；没有实体微信容器测试，无法保证它允许下载文件 |
| 用户提供的完整作业 PDF | 12 页，原文、译稿和参考译文全文保留，可搜索；所有页检查无字符裁切；音标正常 |
| 自测 PDF / 字体失败重试 / 未完成导出 | 题目与答案区完整、失败可重试、未完成禁用 |
| 教师作业批量 PDF | 回归通过；中文命名、同名、零分、缺失结果和取消保留测试 |

可复跑：`npm test`、`npm run lint`、`npm run build`、`node tools/qa-generation-mobile.mjs`、`node tools/e2e-analyze-stream.mjs`、`node tools/qa-teacher.mjs`。

手机微信若没有开始下载，页面会提供明确提示：右上角「…」选择在浏览器打开，再生成下载；Safari 支持文件分享时可使用「保存 / 分享 PDF」存到文件。字体和 PDF 库按需加载，首次导出需要等待下载字体，弱网下会明确报错并允许重试。
