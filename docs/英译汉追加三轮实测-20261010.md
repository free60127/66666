# 英译汉追加三轮实测与修复

日期：2026-10-10。测试模型：服务器当前配置的 deepseek-chat。

## 测试方式

每轮使用自编英文材料，准备含故意错误的中文译稿和正确对照稿，难度依次为高考、四六级、专八。通过真实 HTTP 提交、任务轮询、模型批改、语义复核、评分账本验证及保存链路测试。候选应用使用服务器独立端口和独立文件存储，不改动生产学生成绩，不消耗学生的每日任务次数；模型调用仍消耗服务商 token。

材料保存于 `test/fixtures/en2cn-three-rounds-followup.json`。原始模型结果和诊断输出留在被 Git 忽略的 `tmp/en2cn-followup/`，不提交配置或密钥。

修复后首次完整三轮错译稿耗时分别22、18、32秒；第三轮解释修正后的再次确认38秒、64分（前一次66分）。三轮正确对照稿分别14、20、28秒；最终高难度正确稿再次确认26秒。耗时和模型分数有波动，不是服务时延保证。

## 新问题与已执行的修复

### 1. 不可数数量误读，且AI对照重复学生错误

`a little bread` 被译成“一个小面包”，系统原先没指出问题。少量、尺寸、计数是不同信息：英文没有指定尺寸和个数。

在分析、复核及评分补救共享的规则中补充 a little/little、a few/few、量词与尺寸区分，同时保留 `a little boy` 等形容词用法。little/few 即使第一轮没有检出错误也触发一次复核。实测中学生错误被指出，整篇AI对照也改成“一点面包”。

### 2. 根据邻近主语编造指标归属，误伤正确译稿

原文只说 `prior attainment`，系统因前文提到学校，断言只能是学校的成绩，把“学生此前的成绩”判为错误。学校研究同样可以控制学生的既往学业水平，原文不足以排除该解读。

新增语法主语、分析单位和指标归属的区分；对未指定归属认可合理语境显化，AI可使用中性译法。进一步明确：真实错误不能连带否定同一片段里的合理成分。实测中正确稿不再扣分；错译稿仍指出 adjusted for 误作“提高”，但不再附带宣称“学生”必然错误。

### 3. 整句重复扣分使高难度评分失效

在旧版隔离实例中再次复现。模型为9个理解错误分别扣分，又在表达、语体、流畅度重复扣分，并把同一整句误译当作遗漏扣完整性。复核和评分补救都未完全修正，最终安全回退为无分数。

服务端原先只清理能对应单条 finding 的重复扣分；整句引用覆盖数个已知错误时，无法匹配单条 finding，整个重算提前退出。本次补上对这类跨维度重复引用的识别：引用必须真实存在于原文和译稿，且覆盖的已知 error 均归其他维度，才可清除重复账目。最终仍要求全部真实错误有合法扣分，未知引用、缺失依据或超额账本不能因此放行。

同时明确分项预算上限及账本优先级，不能为了符合总分档位编造其他维度扣分。最终高难度稿有完整合法账本，不再显示无分数。

## 仍需注意

这次样例里的数量漏判、归属误判和账本失败均已修复，不能据此保证任意文本都无漏判或误判。模型仍可能给出不必要的可选润色；这些不扣分，后续可用真实课堂反馈继续校准。

当前总分是独立五维度之和：严重理解失真而中文通顺、无独立漏译的稿件，仍可能在60分以上。此例64分中理解准确仅4/40，不能解释为考试及格或翻译已合格。总评已指出核心信息几乎逐句反转；评分规则也明确禁止“达到60即及格”的推断。后续若要对接考试等级，需教师人工双评分与样本标定，不能用重复扣分强压总分。

新规则用于之后生成的英译汉结果，已保存的旧作业不会自动改分。汉译英的评分维度及批改管线未修改。
