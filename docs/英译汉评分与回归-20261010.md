# 英译汉评分与回归（2026-10-10）

## 评分原则

英译汉采用独立的中文译法要求。忠实传达原文，同时允许中文正常的指代、省略、被字句、拆句和并句，不把与参考译文不同视为错误，也不要求使用成语或文学化措辞。

分项满分：理解准确 40、表达地道 15、语体得当 10、流畅度 10、完整性 25。准确与完整合计 65 分，以免事实严重译错但中文通顺时仍得到高分。汉译英维持原有权重。

每笔扣分必须关联逐句分析中的真实错误，并附英文原文、中文初稿引用及主扣分维度。服务端核验引用、去除可选建议扣分和同一错误跨维度扣分，并计算分项及总分。错误遗漏、引用不存在或评分结构不合法时，只复核一次；仍失败则保留分析，显示评分暂不可用，不编造数字。

该校验保证评分的归因与加总一致，不保证模型对语义和严重程度的判断永远正确。仍需通过更多不同题材、难度和教师人工评分样本校准扣分幅度。

新规则记录为 `en2cn-evidence-v2`。历史成绩不重写；不同翻译方向不混合比较，新旧评分规则不显示分数变化为学习进步。

## 学习链路

- 收藏及题目按条目记录作答语言，混合收藏仍可分别考查中文或英文。
- 中文翻译、造句允许合理异译，交给主观批改；不会因为答案较短就当作英文单词精确匹配。
- 表达卡区分英文原文、中文译法与说明；中文使用中文朗读。
- 结果页分别统计错漏、表达建议及对照学习。英译汉流式过程中不显示未经最终核验的数字分数。

## 回归证据

- 单元与接口测试覆盖重复扣分、可选建议扣分、伪造引用、错误未计入、评分结构归一、复核失败及中文作答。
- 使用同一英文原文、均无参考译文的两份固定初稿调用真实模型：刻意植入 8 处错误的初稿检出 8 处错误，核验后的分数为 54；正确初稿检出 0 处错误、7 条表达建议，核验后的分数为 100。正确初稿触发一次评分复核。
- 以上是有限的人工设计样本，不代表整体评分准确率，也不代表学习效果提升。
- Chromium 安卓视口（393×780）与电脑视口（1440×900）验证结果展示、收藏、离线自测及中文输入提示，未发现页面脚本错误或横向溢出。此项是浏览器视口模拟，不是真机键盘测试。
