# 写作模式接手与验收（2026-10-22）

本次接手承接工作区内已有的写作模式改动。目标是在「课文模式 / 自由模式」旁新增「写作模式」，提供独立的选题、写作、审题指导和提交批改流程。实现与验证均在本地完成，代码未提交或发布。

## 项目与原有改动

- 前端为 React 19 + Vite，`src/App.jsx` 编排课文库、编辑器、结果、历史与账号功能。
- 后端为 `server/index.mjs` 的 Node HTTP 服务，调用兼容 OpenAI 的模型接口；生成任务支持轮询和 SSE，结果供分享链接和历史恢复使用。
- 上一个 agent 已加入写作 prompt、`direction='writing'`、写作指导接口、WritingStudio 界面、66 道真题、34 道自编题和 18 张原始配图。
- 本次沿用上述实现和题库数据，补齐功能衔接、缺失资源及验证。另从原始试卷核对并重新提取考研英二 2022、2023、2026 的配图；没有重新逐卷核对整个真题库。

## 本次完成

1. 修复写作指导一直停在生成中的问题。`submitAndPoll` 返回结果对象，不执行传入的 `onData`；现在正确读取返回值，并防止切题、卸载后的迟到响应覆盖当前题目。
2. 接通专四、专八的 `excerpt` 阅读材料，供题目展示、AI 指导、批改及评分补救使用。材料、图片描述和目标词数随批改结果保存，分享、复制和打印保留审题依据。
3. 写作草稿按题目分开保存；自定义题目使用稳定标识。整篇写作与分段带写互相接续，刷新、快速返回、页面隐藏及组件卸载时保留最后输入。
4. 将写作草稿和写作模式状态纳入本机账号缓存隔离。切换账号前刷新草稿，卸载后的旧工作区不能把原账号内容写进新账号。
5. 写作提交不携带翻译课文或当前班级翻译作业。写作练习对比只匹配同一道题目；结果和复制内容使用写作文案。
6. 作文没有逐句错误但模型漏写评分时，也尝试补救四维评分；补救仍不可用时沿用现有明确的无数值评分提示。
7. 补齐考研英二 2018、2020 两张缺失饼图，按已有题面数据绘制 SVG，并标注重绘来源。目前 20 道配图题均有实际资源。
8. 区分拍照与图片导入入口，写作 OCR 遵循全局识别模式；隐藏写作模式中不适用的 DOCX、翻译素材及课文保存入口。优化手机操作栏，检查 320px 和 390px 宽度布局。
9. 题库及写作页的配图均可点击打开原生模态大图，支持缩放、滚动、适合窗口、Esc/遮罩关闭及焦点恢复。考研英二 2026 补全百分比、类别标签和标题；2022 补全标题与单位（并将文字说明中错误的“亿件”更正为“10亿件”）；2023 补全标题及健康素养定义。新资源使用新 URL，已有草稿按题号更新题目资料，不丢作文。
10. 检查全部 18 道阅读材料题。Excerpt 1/2 分别独立显示，增加标题、段间空白和正文分段；同时修复专四 2015、2016、2019 的文章标题混入正文。结果页、复制、打印使用相同的材料结构，文字顺序及完整内容保留。
11. 将“边生成边显示”移入 AI 接入设置，沿用原有开关、保存键和生成逻辑，界面说明选择会自动记住。
12. AI 引导移至右侧编辑框上方，按当前段落展示编号思路、关键词和独立折叠的参考句式。可选模型推荐的立场/分析角度，也可自定；选择会重新调用模型生成四段指导，保留已写作文。图表题按题意提供原因、影响、建议等角度，纯客观图表不额外要求表态。审题、全文安排与避坑提醒集中在可展开区域。指导和采用的角度随各题草稿保存，失败时保留上一版，切题后的迟到响应不能覆盖新题。

```text
npm run build
npm run lint
npm test
npm run test:writing
npm run test:writing:e2e
```

写作 HTTP 测试与浏览器测试使用独立的临时存储和本地 mock 模型，不调用付费模型，不使用生产 Redis。浏览器截图保存于 `tmp/writing-qa/`。

最终验收：生产构建成功，`npm test` 全量通过（前端 24 个测试文件、212 项测试），写作 Chromium 验收全部通过，`git diff --check` 通过。浏览器包含图片预览/缩放/关闭/焦点恢复、材料分篇、设置持久化、引导布局、角度请求、句式折叠、草稿与指导恢复，以及历史、分享、打印和手机布局检查。日志保存在本机 `tmp/writing-qa/full-suite-final.log` 与 `browser-final.log`。本地预览服务已更新并运行于 `http://localhost:8787`，尚未推送或部署到正式网站。

已另外使用项目现有模型配置做过一次真实写作批改，使用独立本地存储：返回 88 分，四个分项之和与总分一致，包含 10 个句群解析、完整提升版和范文，准确识别预置的 `Students learns → Students learn` 错误。单篇实测验证调用和返回结构，不能代替各考试评分质量的长期评估。原始返回保存在本机 `tmp/writing-qa/live-result.json`。

新引导也使用现有模型配置在独立临时存储实测：为英二 2026 选择“好奇心与观察力”和“亲子陪伴”两种不同角度，均得到完整四段、每段 2–3 条思路、关键词与参考句式，主体段内容随角度变化。原始返回保存在本机 `tmp/writing-qa/live-guidance.json`。

`lint` 没有错误，仍有 `server/admin.test.mjs` 内两个既有的未使用变量警告；Vite 保留原有大文件包体积提示。

复跑全量测试时，既有 `server/jobs.test.mjs` 的固定 mock 端口 9881 被 Windows 拒绝绑定；已改为系统分配端口，避免依赖该固定端口。
