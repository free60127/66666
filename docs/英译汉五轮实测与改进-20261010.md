# 英译汉五轮实测与改进报告

日期：2026-10-10。对象：回译本的英译汉批改全链路。

## 1. 怎么测的

自行编写五篇英文材料，难度、句法与逻辑复杂度依次递增；中文译稿故意夹入明确错误，同时保留成立的中文意译、省略与拆合句。样本与预期错误见 `test/fixtures/en2cn-five-rounds.json`，共 **31 处明确错误**。

使用服务器当前配置的真实模型 deepseek-chat，实际请求 `/api/analyze`，等待后台任务完成，再通过任务接口读取已保存结果。初测使用线上版本；候选版本在同一服务器的隔离端口和临时存储中运行，不改真实账号或班级数据。模拟通过 HTTP 任务链路完成；另外用浏览器加载实际生成结果，检查桌面与安卓触屏尺寸的显示。这不是安卓真机或输入法测试。

不是只跑五次取最好结果：五轮初测后又完整重放两次，另做正确译文对照与针对性重放。中间出现过漏判、评分不可用和复核重复列错，下文保留这些发现。原始任务响应留在本机 `tmp/en2cn-five-rounds/`，不包含提交用的 API Key。

**重要的比较限制：** 初测五份自由英文原文全部被错误附上同一篇不相关的内置中文参考，修复后不再附加。前后差异同时包含参考污染修复、提示词和复核机制变化，不能把分数变化单独归因于某条评分规则，也不能解释成学生提高了多少分。

## 3. 共性缺点与已执行的修改

### P1：自由模式错误套入内置课文

初测实际任务的 original 都出现不相关的教师节课文，并带上错误的册次、课号。空英文标题导致 `includes('')` 恒成立，弱标题匹配随后被自动接受；英译汉的全文匹配还错误使用中文字段。

已修复：空标题不参与标题匹配；按翻译方向匹配英文或中文来源；自由题自动关联必须是无歧义的高置信全文精确匹配，标题或编号线索只作建议。显式选中的内置课文仍可正常使用。新增空标题、无关来源、仅标题、仅编号、双向精确匹配和歧义回归测试。

### P1：局部漏增译被扣掉几乎全部完整性分

公交初测将一个新增免费乘车承诺扣了完整性 25/25 分；专八一个整句漏译扣了 21/25 分。完整性点评还混入已经在理解准确项扣过的误译。

已修复：局部漏增译的单条扣分超过 8 分、且引用范围不足全文三分之一时，必须重新复核；大范围真正缺失仍可重扣，但需要覆盖相应原文的证据。分项点评从实际通过校验的扣分记录生成，避免在另一项点评中再次宣称同一误译是“漏掉了”。**这是防止明显异常的复核阈值，不是精确的考试评分公式，也不是每条固定扣 8 分。**

### P1：提示词优化会引入新的漏判

只调整提示词后的重放，高考把“20个百分点”降成可选建议，公交漏掉末尾免费乘车增译。说明初测找全不代表改完就稳定。

已修复：高风险英译汉增加一次独立语义复核，重新核对全文源信息与全文译稿，包括数字口径、否定范围、必要条件、比较、证据强度、时态情态及尾部新增事实。新问题和改动必须引用真实原文、真实译稿并使用有效编号；无依据的改动被拒绝，保留首次分析。一次语义复核限时 45 秒，评分账本如仍有问题最多再补一次评分请求，限时同为 45 秒。不是无限循环修复。

### P1：解释自己也在过度推断

模型多次把 not all 解释为“有些新、有些旧”；这是不成立的逻辑承诺。源文只保证不是全部新的，不能推出一定有新工具。不能把“与原文不矛盾”当作“准确传达原文”。

已修复：在提示和复核中明确这些逻辑边界；对有真实引用的 `not all → 都不是` 这一窄场景，服务端明确纠正解释，防止再次输出“有新有旧”。同时清除可能沿用错误解释的学习例子。其他否定结构仍需模型结合上下文判断，没有用简单关键词替代全文理解。

### P1：缺少可核验引用，导致有批改却无分数

研究材料初测的错误条目缺少评分引用；单独补评分仍无法与已有条目匹配。候选版本的整句漏译还使用了“学生译稿无对应句”作为 from，实际上这段话不在学生译稿里，账本校验会失败。

已修复：输出结构显式要求英文原文引用及唯一主要评分项；复核修正漏译占位符；评分补救可用唯一且真实的译稿片段定位旧条目，不接受歧义匹配或捏造引用。仍无法核验时不捏造分数。复核失败会在学生结果页提示实际状态。

### P2：复核可能重复列出同一条错误

专八重复试跑时，复核把原有的结论否定错误又按整句新增一遍，导致账本无法验收。

已修复：新增条目与原条目在原文和译稿范围同时重叠、且类别和主维度相同时，保留原条目，不新增重复扣分；重新校验实际保留的账本。新增测试覆盖“分句错误又被扩写成整句错误”。这只处理结构上明确重叠的重复，不宣称能自动识别所有语义重复。

### P2：整句漏译的“改成”可能误导学生删除邻句

漏译用相邻已有译稿作定位时，若直接显示“邻句 → 漏掉的句子”，学生容易把本来存在的句子删掉。

已修复：补译内容没有保留锚点时，结果页显示“补充遗漏信息（附近译稿……）”，不用划掉相邻句；教师批量 PDF 使用相同说明。若模型已经给出“保留邻句并补入遗漏”的完整替换，则保留原替换展示。

### P2：同义替换过多，给人“原译不够好”的错觉

例如摆椅子/搬椅子、客流量/乘客数量、领取/获取、继续试验/进一步试验。还会为了“更贴字面”添加反而等词。

已修改提示和复核标准：正确的中文意译、省略、拆合句不扣分；另一个合法译法标为学习对照，不默认称更高级；有实际可读性收益才称可提升。**这项仍有残余：专八实测保留了两条可选建议，“反而”的优越性仍值得商榷。它们没有扣分，但建议内容还需要人工抽查。** 不用机械过滤全部可选建议，以免丢掉真正有价值的表达训练。

### P2：手机结果页被术语与音标撑宽

实际研究材料的 statistically significant 词汇卡把收藏按钮挤到 360px 屏幕之外，浏览器视觉宽度扩大到 390px。

已修复：词汇标题区允许换行，长词与音标可断行；未用横向裁切隐藏内容。桌面和安卓尺寸分别加载五份实际输出，检查结果页无白屏、无横向扩宽，以及补译说明和逻辑边界解释可见。

## 4. 与汉译英批改应该有何不同

| 方面 | 汉译英重点 | 英译汉重点 / 本次处理 |
| --- | --- | --- |
| 核心错误 | 英文选词、搭配、冠词、单复数、时态、句法，同时保证信息忠实 | 首先判断英文读懂没有：否定范围、条件、因果、指代、数字、情态；再评中文 |
| 表达标准 | 英语句法及搭配是否成立 | 中文是否准确自然、语体恰当；不强制保留英语句式、每个主语或每个句号 |
| 参考的地位 | 参考也是一种译法，不是唯一答案 | 更不能因参考用了成语或文学表达，就要求学生照抄；源文是事实依据 |
| 句子对齐 | 可调整英文结构，不能因此漏信息 | 支持跨相邻句、拆句与合句，检查全文是否已表达，不能逐句硬判漏译 |
| 改法 | 落在英文上，解释英文用法 | 改法落在中文上，解释英文理解和中文组织；补译与替换区别展示 |
| 评分 | 现有汉译英五项各 20 分 | 保持独立 40/15/10/10/25 权重；基于证据记账，真实误译不因中文通顺被忽略，同一事实不跨项重复扣分 |
| 学习材料 | 英语搭配、句式、表达以及英文作答 | 中文译法、语体与信息处理，中文作答和朗读；不强制成语，不套用英文作文长度标准 |

本次语义复核和解释保护只用于英译汉。两种方向都必须忠实于原文；差异不意味着汉译英可以忽略否定与数字。

## 5. 对照、回归与尚需改进之处

正确高考稿实测 100 分、0 个必改，保留两条可选建议。专八最初的“正确稿”其实把确定的“后果严重”改成“可能严重”，实测被扣 2 分是有依据的，不应称误判。修正这个情态后再次实测为 100 分、0 个必改、0 个可选建议。对照范围只有这两篇，不能据此声称对所有好译文都无误判。

回归使用 `npm test` 的隔离存储和测试额度，服务端整套测试及 22 个 UI 测试文件、197 个 UI 用例通过。另验证 lint、生产构建与浏览器尺寸。新增回归重点是源文引用、扣分重复、全文新增事实、语义复核边界、中文建议展示及教师 PDF 的补译说明。

后续最值得做的不是统一加分：

1. **教师盲评标定。** 本次 31/31 是这五份样本的结果，模型重放曾漏判，评分也仍有波动。同一专八错误稿复跑出现 67、70 等分数。准备 30–50 份匿名译稿，由教师先标事实错误、严重性和分数区间，再对比模型。
2. **校准严重程度和权重。** 理解准确满分 40 的规则意味着“中文流畅但事实大面积说反”可能仍得较高分；研究样本 7 个重要错误得 72 分也值得教师核对。不能因用户觉得分低就无条件抬分，也不应未经标定任意换权重或硬压分数。本轮没有修改权重，只修复证据、重复扣分和明显局部异常。
3. **为评语做独立人工抽检。** 错误检出正确不代表每句解释、习语、同义词和 AI 全文译稿都正确。复核重点是错漏与证据，不等同于逐个验证全部学习卡。
4. **扩大反向对照。** 下次增加被动与省略、多义词、文化负载词、否定嵌套、指代跨段、法律政策语体、全文乱序而信息保留等样本；同一材料至少重放两次，记录漏判、误判和分数波动，而不是只报一次命中率。
5. **观察成本与等待时间。** 高风险任务新增一个模型请求，计入同一练习任务但会增加真实模型费用和等待时间；本次记录不能当作固定 SLA。若复核不可用，向学生展示实际状态，保留第一次批改。

历史分享结果保留原批改，不悄悄改写已交作业的分数。新任务应用更新后的规则；不同规则版本之间不展示未经校准的“进步了多少分”。
