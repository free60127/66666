# PDF 导出版式修复与验证

## 问题与修复

学生导出和教师批量导出原先共用纯文本生成器：近义词、例句等结构先被展平成段落，再写入 PDF，网页的卡片层次和错词标记因此丢失。

改为直接读取结构化结果，保留综合评分、分项条形图、教师评语、材料对照、逐句改错、独立近义词卡片、音标和例句。错误标记与网页版共用匹配逻辑，可选提升和漏译插入锚点不涂成错误。原稿、AI 译文、参考译文使用各自颜色。

使用 A4 纸张和可搜索的矢量文字；短卡片尽量保持完整，长卡片按文字行跨页，并显示续页标签。标题与后续内容、分项分数与说明保持在同一页，避免空卡片边框和孤立标题。纸张宽度、字号及分页适配 A4，不是对网页长截图的逐像素复制。

视觉检查另外发现：合并字体含奇数字形偏移，fontkit 生成短 TrueType 字体子集时会截断这些偏移。文档文字可提取，阅读器却不显示部分字形。已将源字体字形记录补齐为两字节对齐，保留中英文及音标覆盖；重建字体后可运行 `tools/normalize-report-font.py`。新增回归测试直接解码 PDF 内嵌字体并检查字形轮廓，防止仅文字层通过而显示失败。

## 验证

- 汉译英演示作业 10 页、真实模型生成的高难度英译汉测试作业 12 页、超长解释压力样例 3 页，共 25 页，全部渲染并检查。中文及音标可见，近义词分卡，无字符越界；超长解释 200 次重复完整保留。
- 桌面 Chromium、Pixel 5 安卓模拟视口、iPhone 13 WebKit 各实际点击两个方向的 PDF 导出，共 6 次下载；持久下载链接再次点击也能下载，没有页面 JavaScript 异常。这是浏览器模拟，不等同于微信内置浏览器或手机真机验证。
- 教师 ZIP 导出回归通过：学生姓名、零分、北京时间日期、同名去重、多页、失败名单和取消。
- 新增 PDF 卡片结构、错误/插入标记、音标和短文档字形回归通过。
- 完整 `npm test` 通过（包含 22 个 UI 测试文件、197 项 UI 测试），随后最终 PDF 回归再次通过；`npm run lint`、`npm run build` 通过。
- 导出仍只在用户点击后加载 PDF 依赖与字体；已有 PDF 依赖包体积提示仍在，未增加 PDF 运行依赖。

旧作业无需重新批改，刷新网站并重新导出即可应用新排版。已下载的旧 PDF 文件不会自动改变。新旧作业的分数和批改内容不会因导出而改变。
