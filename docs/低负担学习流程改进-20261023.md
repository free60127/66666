# 低负担学习流程改进

日期：2026-10-23。基线：`0497911`。范围：本机优先的五项学习体验改进。

## 已实现

1. **复习先回想、再看答案**：错题卡正面只显示原表达，翻面才显示修改表达与解释；兼容旧收藏的“原句 → 修改句”格式。表达卡有释义时可先用释义回想表达。
2. **原稿与修改稿关联**：修改稿保存直属原稿和最初原稿的任务编号，独立保存正文；报告比较分数、错误类型和两份正文。优先读本机已有报告，缺失时由用户点击载入原稿，无须再次调用 AI。
3. **自测进度恢复**：答题过程仅存浏览器，最近三份自测有独立编号；切页、刷新和账号切换前保存。不同账号隔离，多标签页编辑不同题目可以合并，同题冲突提示备份，不覆盖另一页的答案。AI 迟到结果不会套到已经修改的答案上。完成后才把正确率等摘要纳入既有进度同步。
4. **按题型组织写作**：书信、图表、材料和观点作文使用不同的步骤、提示和词数分配；本地规则识别，可手动选择。自定义题目可指定目标词数。切换题型保留正文；现有 AI 引导请求带上题型，不另发分类请求。
5. **学习首页与下一步**：推荐未完成的作文/翻译、自测、到期卡片、待完成的批改和需要修改的已有报告；按当前难度提供尚未完成的新题。支持选择写作或翻译重点。手机进入首页收起侧栏；班级作文继续保留作业归属，未激活的班级作业经已有作业入口核对状态。

## 资源边界

- 首页推荐、题型判断、复习翻面、草稿恢复均在浏览器计算，不新增定时任务或服务端轮询。
- 自测题目、逐题答案和批改过程不上传云同步；每份本机记录上限 300,000 字符，最多保留三份。
- 自测完成摘要复用 `progress` 和现有同步节流，总进度仍受现有 2,000 条上限约束。反复打开已完成自测不会重复上报同一摘要。
- 作文历史只同步必要的关联信息；不把长题干、材料全文或图片内容重复塞进历史索引。题库配图只记录已有静态资源路径。
- 原稿报告缺失时的“载入原稿对比”会产生一次已有报告读取；重新提交批改和主动生成 AI 指导仍沿用原有额度与调用方式。
- 本次没有调整数据库套餐、任务保留期、队列容量、自动同步频率或公共 AI 额度。增量负担较低，但不代表既有运营成本为零。

## 使用边界

- 换浏览器或清空浏览器数据后，自测逐题作答不能从云端恢复；只有完成成绩摘要随账号同步。
- 原稿已删除或过期且本机也没有报告时，会说明暂时无法比较，当前修改稿仍可使用。
- 对比依据两次批改结果，不保证评分完全一致，也不把“本次未检出”当作已经掌握。
- 本地题型判断覆盖常见题干；特殊命题可手动选题型，正文不会因此清空。
